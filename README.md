# EcoShip — Sustainability Dashboard Wireframe

A browser-based sustainability dashboard prototype built with HTML, CSS, JavaScript, and Chart.js.

## What's in this repository
- `index.html` — dashboard interface and visualization logic
- `vercel.json` — deployment configuration

## Run locally
1. Clone the repository.
2. Open `index.html` in a modern browser.
3. Allow the Chart.js CDN to load if connected to the internet.

## Purpose
Demonstrates a dashboard layout for presenting sustainability information and charts. This repository is a **wireframe/prototype**, not a verified production analytics system.

## Next engineering steps
Validate charts against real datasets, add automated browser tests, improve keyboard/screen-reader accessibility, and document data provenance.
